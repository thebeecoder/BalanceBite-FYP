# BalanceBite - FINAL YEAR PROJECT (BS(AI))

BalanceBite is a Flutter project developed as a Final Year Project. It focuses on nutrition and balanced eating and includes trained model files used by the application.

## Project Poster

[View the BalanceBite poster](POSTER%20(BALANCEBITE).pdf)

## Project Structure

- `lib/` — Flutter application source code
- `assets/` — application assets and model download instructions
- `test/` — project tests
- `android/`, `ios/`, `web/` — platform-specific project files

## Trained Models

The trained model files are hosted on Google Drive because they are too large to store in this repository. Download links and placement instructions are in [`assets/MODEL_DOWNLOADS.txt`](assets/MODEL_DOWNLOADS.txt). Download the files and place them at the paths expected by the app.
